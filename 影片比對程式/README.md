# 雙影片同步對比播放器 (Dual Video Player - 0 距離無縫版)

專為影片比對（如馬賽克解除前後對比、畫質修復、濾鏡效果等）設計的高精度雙影片同步播放工具。

## 🌟 主要功能特點

1. **★ 0 距離無縫貼合 (Zero-Gap Seamless Comparison)**：
   - 左右兩支影片在正中央**完全 0 距離無縫相接**，無任何黑邊或多餘間隙干擾。
   - 程式會依據兩支影片的解析度與長寬比自動適應高度，讓左右畫面像素在交界處無縫對齊。
   - 提供「**0 距離貼合**」開關與「**1px 參考線**」切換功能，方便精準定位分界處。

2. **各自獨立自訂起始時間點 (Start Time Inputs)**：
   - 兩支影片各自下方均有專屬的「起始時間點」輸入欄位。
   - 支援多種輸入格式：`mm:ss.sss`（例如 `00:01.250`）、純秒數（例如 `5.2`）或 `hh:mm:ss`。
   - **「📌 設為當前」**：暫停時可一鍵將當前畫面時間填入起始點。
   - **微步對齊按鈕**：提供 `-1s`、`-0.1s`、`+0.1s`、`+1s` 微調按鈕，精確抓到完全同步的畫面幀。

3. **影片中央下方控制區 (Center Bottom Controls)**：
   - **`▶ 開始播放`**：兩支影片自各自設定的起點同步播放。
   - **`⏸ 暫停`**：兩支影片同步暫停。
   - **`⏮ 回到起始點`**：同步重設並跳轉回兩支影片各自設定的起始幀。
   - **`◀ 上一格` / `下一格 ▶`**：單格步進（約 33ms 一幀），超適合放大檢視馬賽克處理細節。
   - **同步滑動時間軸**：拖動進度條時，兩支影片會精準維持時間差同步跳轉。
   - **自動時差偏差校正**：播放時每 100ms 自動監控並校正解碼延遲，避免影片不同步。
   - **循環播放**：可勾選自動循環。
   - **倍速選擇**：支援 0.25x、0.5x、1.0x、1.5x、2.0x 慢速與快速播放。
   - **各自獨立靜音**：兩邊可分別勾選靜音，避免兩個音訊混雜。

4. **★ YouTube 風格全螢幕模式 (YouTube-style Fullscreen Experience)**：
   - **一鍵全螢幕**：按鍵盤 **`F`** 鍵、點擊畫面右下角 **`⛶ 全螢幕 (F)`** 按鈕，或是**直接對影片畫面滑鼠雙擊 (Double Click)**，即可進入全螢幕！
   - **退出全螢幕**：按 **`Esc`** 鍵、按 **`F`** 鍵、點擊 **`🗗 退出全螢幕 (F)`**，或是再次**滑鼠雙擊畫面**即可退出。
   - **沉浸式 0 距離畫面**：全螢幕時左右影片無縫 0 距離完全鋪滿螢幕，排除所有多餘邊框干擾。
   - **YouTube 懸浮控制面板 (Floating Overlay)**：控制面板懸浮在畫面底部中央，具備現代毛玻璃半透明黑底。
   - **閒置自動隱藏 (Auto-Hide on Idle)**：滑鼠停止移動 2.5 秒後，控制面板與滑鼠游標自動淡出隱藏；滑鼠稍作移動立即重新浮現！
   - **防誤觸設計**：滑鼠停留在控制列或操作時間輸入時不會自動隱藏；在時間欄位輸入文字時按鍵不會誤觸播放或全螢幕。

5. **鍵盤快捷鍵**：
   - `Space`（空白鍵）：播放 / 暫停 切換
   - `F`：全螢幕進入 / 退出 切換
   - `Esc`：退出全螢幕
   - `雙擊畫面`：全螢幕進入 / 退出 切換
   - `←` / `→`（方向鍵）：同步後退 / 前進 0.1 秒
   - `Home`：回到起始點

## 🚀 如何啟動程式

本資料夾提供兩種超方便的執行方式：

### 方式 1：Windows 桌面版應用程式（推薦）
- 直接對 **`run_player.bat`** 滑鼠點兩下即可一鍵啟動！
- 或是開啟終端機執行：
  ```bash
  python dual_video_player.py
  ```

### 方式 2：瀏覽器獨立版（免裝環境，隨開隨用）
- 直接以 Chrome 或 Edge 瀏覽器開啟 **`dual_video_player.html`**。
- 將左右兩支影片拖曳進去即可立即比對！
